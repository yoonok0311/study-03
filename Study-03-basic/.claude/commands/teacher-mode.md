여러 학생의 퀴즈 성적을 한눈에 보고 비교하는 선생님 모드의 모든 단계를 순서대로 실행합니다. 입력: $ARGUMENTS

각 단계는 해당 명령어 파일(`.claude/commands/teacher-*.md`)을 읽고, 그 파일의 스크립트를 대문자 상수만 채워 **그대로** 실행합니다. 스크립트를 이 파일에 따로 복사하지 않으므로 개별 명령어를 고치면 통합 실행에도 그대로 반영됩니다.

| 단계 | 명령어 | 하는 일 |
|---|---|---|
| 1 | `/teacher-sample` | (입력이 `샘플`일 때만) 연습용 가상 학생 기록 만들기 |
| 2 | `/teacher-collect` | 학생 기록 파일 검사, 중복 제거, `teacher/class.json`으로 합치기 |
| 3 | `/teacher-overview` | 반 전체 성적표 (모든 게임, 전체 기간) |
| 4 | `/teacher-weak` | 약한 카테고리·난이도, 도움이 필요한 학생 |
| 5 | `/teacher-compare` | 학생 비교 |
| 6 | `/teacher-report` | HTML 리포트 파일 |

## 입력 해석

* `비교` 앞은 기록 위치, 뒤는 비교할 학생 이름입니다.
* 기록 위치: 비우면 `teacher/inbox`, `샘플`(또는 `sample`)이면 1단계를 실행하고 `teacher/sample`, 그 밖에는 공백으로 나눈 폴더·`.json` 파일 경로 (2단계의 `SOURCES`)
* 비교할 학생: 2~6명. 없으면 3단계 성적표에서 순위가 있는 학생 중 1위와 마지막 순위 학생을 비교합니다 (순위가 있는 학생이 2명 미만이면 5단계를 건너뛰고 보고에 적음).
* 이름이 1명뿐이거나 7명 이상이면 사용법(`/teacher-mode [기록 위치 | 샘플] [비교 이름1 이름2 ...]`)을 보여 주고 멈춥니다.

## 공통 규칙

* 모든 스크립트는 `Study-03-basic` 폴더에서 Node로 실행하고, 셸 heredoc은 `\\`를 바꿀 수 있으므로 Write 도구로 임시 파일(scratchpad)에 저장해 실행합니다.
* 시작하기 전에 저장소 루트 `.gitignore`에 `Study-03-basic/teacher/`가 있는지 봅니다. 없으면 `# 선생님 모드 학생 기록 (학생 이름 포함)` 주석과 함께 추가하고, 보고에 적습니다.
* 파일은 `teacher/` 안에만 만듭니다 (`sample/`, `class.json`, `reports/`). 게임 코드와 문서는 고치지 않고, 커밋하지 않습니다.
* 각 단계의 **통과 조건**은 그 명령어 파일에 적힌 것을 따릅니다.

## 실패 처리

스크립트가 `실패:`로 시작하는 줄을 출력하거나 0이 아닌 코드로 끝나거나 통과 조건을 못 지키면 **그 자리에서 멈추고** 다음 단계로 가지 않습니다. 고쳐서 다시 시도하지 않습니다. 3~5단계는 서로 의존하지 않지만, 하나가 실패해도 뒤 단계를 이어서 하지 않습니다 (일부만 맞는 결과를 보고하지 않게).

```
❌ teacher-mode 중단: N단계 (명령어 이름)
- 오류: 스크립트 출력 그대로
- 원인: 추정되는 원인 한두 줄
- 파일 상태: teacher/ 안에 만든 파일 (없으면 "없음"). 6단계에서 실패했으면 만들다 만 리포트를 지움
- 해결 방법: 사용자가 할 일 (예: teacher/inbox에 파일 넣기, 이름 확인)
- 완료된 단계: 1~(N-1)단계 결과 요약
```

## 결과 보고

맨 위에 `✅ teacher-mode 완료: 학생 N명, 기록 M판, 반 평균 정답률 A%, 리포트 경로` 한 줄 요약을 적고 아래 순서로 보여 줍니다. 각 명령어 파일의 "보고" 항목을 짧게 줄여 씁니다.

1. **단계별 결과**: 단계마다 통과 여부와 핵심 수치 한 줄씩 (건너뛴 단계는 이유)
2. **수집**: 파일 수, 중복·형식 오류·이름 정리, 같은 학생일 수 있는 이름 ⚠
3. **반 성적표**: 학생별 표 (순위, 이름, 정답률, 평균과 차이, 푼 문제, 판 수, 추이, 마지막 플레이, 표시)
4. **약점**: 카테고리별 반 정답률(낮은 순), 학생 × 카테고리 표의 ⚠ 칸, 도움이 필요한 학생
5. **비교**: 비교한 학생과 주요 항목 (정답률, 카테고리별, 추이, 최고 점수), 차이가 큰 항목
6. **리포트**: 경로, 크기, 여는 방법
7. **선생님께 드리는 제안**: 3~5줄. 반 전체 복습이 필요한 카테고리, 개별 지도가 필요한 학생과 추천 연습(`카테고리 도전 · 카테고리`, 필요하면 난이도 "쉬움"), 오래 쉰 학생 독려, 기록이 적은 학생에게 더 풀게 하기

샘플 데이터로 실행했으면 요약 줄과 제안에 "가상 학생 데이터"라고 밝힙니다.
