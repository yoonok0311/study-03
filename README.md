# 상식 퀴즈 (Study-03)

한국어 4지선다 상식 퀴즈 웹 게임입니다. 순수 HTML, CSS, JavaScript로 만들어서 설치나 빌드, 서버 없이 브라우저만 있으면 실행됩니다.

VibeCoding 학습 시리즈의 세 번째 프로젝트입니다.

## 바로 플레이하기

- **상식 퀴즈**: https://yoonok0311.github.io/study-03/
- **퀴즈 게임 - 지식의 도전**: https://yoonok0311.github.io/study-03/Study-03-basic/

## 내 컴퓨터에서 실행하기

1. 저장소를 내려받습니다.
   ```bash
   git clone https://github.com/yoonok0311/study-03.git
   ```
2. `index.html`을 브라우저로 엽니다. 두 번째 버전은 `Study-03-basic/index.html`을 엽니다.

## 두 가지 버전

| | 상식 퀴즈 (루트) | 퀴즈 게임 - 지식의 도전 (`Study-03-basic/`) |
|---|---|---|
| 카테고리 | 한국사 · 과학 · 지리 · 일반상식 | 한국사 · 세계지리 · 과학 · 예술과 문화 |
| 문제 수 | 44문제 (카테고리별 11) | 44문제 (카테고리별 11) |
| 게임 모드 | 전체 도전(40) · 카테고리 도전(10) · 스피드 퀴즈(20, 문제당 15초) | 같음 |
| 난이도 표시 | 배지로 표시 | 표시하지 않음 |
| 해설 | 화면 안에 바로 표시 | 1초 뒤 모달 팝업 |
| 결과 화면 | 점수, 정답률, 평균 응답 시간, 최장 연속 정답, 힌트 사용, 카테고리별 결과 | 같음 |
| 디자인 | 흰색 카드, 인디고 색상 | 보라색 그라데이션 |

두 버전 모두 난이도가 카테고리마다 easy 4, medium 5, hard 2문제로 같습니다. 아래 주요 기능(게임 모드, 점수, 힌트, 타이머와 일시정지)도 두 버전이 같은 규칙으로 동작합니다.

## 주요 기능

- **게임 모드**: 전체 도전(카테고리마다 10문제, 40문제), 카테고리 도전(10문제), 스피드 퀴즈(20문제, 문제당 15초)
- **점수**: 정답 기본 10점에 보너스가 붙습니다.
  - 10초 안에 답하면 +3
  - 힌트를 쓰지 않으면 +2
  - 연속 정답 콤보: 3~4연속 +2, 5~9연속 +3, 10연속 이상 +5
- **힌트**: 게임당 3번, 오답 2개를 지워 줍니다.
- **타이머와 일시정지**: 문제마다 걸린 시간을 재고, 일시정지하면 문제를 가리고 타이머를 멈춥니다.
- **문제 순서 섞기**: 시작 화면의 체크박스(기본 켜짐)로 매 게임 문제 순서를 무작위로 바꿉니다.
- **정답·오답 표시와 해설**: 답을 고르면 정답은 초록, 오답은 빨강으로 표시하고 해설을 보여 줍니다.
- **키보드 조작**: `1`~`4` 키로 답을 고르고 `Enter`로 다음 문제로 넘어갑니다. `H`는 힌트, `P`나 `Esc`는 일시정지입니다.

## 문제 추가하기

루트 버전은 `questions.js`의 `QUESTIONS` 배열에, `Study-03-basic`은 `questions.js`의 `quizQuestions` 배열에 항목을 추가합니다.

```js
{
  id: 45,
  category: "과학",
  difficulty: "medium",          // easy | medium | hard
  question: "문제 내용",
  options: ["보기1", "보기2", "보기3", "보기4"],   // 반드시 4개
  correctAnswer: 1,              // 정답 보기의 번호 (0부터 시작)
  explanation: "해설"
}
```

- 루트 버전은 새 카테고리 이름을 쓰면 카테고리 선택 목록에 자동으로 추가됩니다.
- `Study-03-basic`은 시작 화면의 카테고리 칩이 `index.html`에 직접 적혀 있어서, 새 카테고리를 쓰려면 그 부분도 함께 고쳐야 합니다. 문제 수를 바꾸면 `index.html`의 "44개의 도전적인 문제" 문구도 고칩니다.

## 문제 검증 가이드라인

모든 문제는 아래 기준으로 점검했고, 주요 수치는 웹 검색으로 출처와 대조했습니다.

1. **정답이 하나뿐인가?** 다르게 해석될 수 있으면 조건을 적는다 (예: 면적 기준, 2024년 기준).
2. **최상급 표현에 기준이 있는가?** '가장 큰', '최초의' 같은 표현에 측정 기준을 적는다.
3. **시간과 범위가 명확한가?** 바뀔 수 있는 정보는 시점을, 지리나 분류는 범위를 적는다.
4. **교차 검증했는가?** 의심스러운 정보는 출처 2개 이상으로 확인하고, 논란이 있는 내용은 주류 학설을 따른다.
